No chart library, no JS, no external requests -- the CSP forbids all three, and a dashboard that needs 90KB of JavaScript to draw eight bars is a dashboard that breaks when the CDN does. Hover uses , which browsers render as a native tooltip with no script at all. Every chart also has a table fallback, so the data is reachable by a screen reader and by anyone who prefers numbers. Colours come from the validated categorical palette in admin.css (--viz-1..--viz-5). That order passed the lightness band, chroma floor, colour-vision-deficiency separation, normal-vision floor and contrast checks against this exact dark surface.
