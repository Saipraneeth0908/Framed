Analytics is not connected yet

Business analytics lives in Metabase reading the mart schema as bi_reader, embedded here with a signed token so you only sign in once. Two environment variables switch it on: 

METABASE_SITE_URL=https://metabase.framedobsessions.com
METABASE_EMBED_SECRET=<the embedding secret from Metabase admin>

Start it locally with docker compose --profile bi up -d metabase, then point it at this database using the bi_reader role. That role is read-only and can see the marts and nothing else — a runaway question cannot lock checkout or read customer PII.
