Metabase is optional

Every dashboard in the other tabs is first-party and always works. Metabase adds one thing those cannot: a question builder, so you can ask something nobody wrote a page for — without waiting on a developer. 

METABASE_SITE_URL=https://metabase.framedobsessions.com
METABASE_EMBED_SECRET=<the embedding secret from Metabase admin>

Start it with docker compose --profile bi up -d metabase, then connect it to this database as bi_reader. That role is read-only and can see the mart schema and nothing else, so a runaway question cannot lock checkout or read customer PII.
